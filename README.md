# Abdelrahman Ramadan

IT developer based in Athens, Greece. I build Python and web applications, with projects spanning retrieval-augmented generation, cybersecurity data processing, and invoicing software.

## Selected work

### [SY335C Maintenance RAG](https://github.com/Abudirrr/sy335c-maintenance-rag)

A local AI prototype for exploring SANY SY335C maintenance manuals. I built PDF ingestion, page-aware chunking, MiniLM embeddings, FAISS search, hybrid reranking, FLAN-T5 generation, and a FastAPI interface with citations and evidence previews. The project includes retrieval baselines and procedural evaluation, with documented limitations.

**Stack:** Python · FastAPI · FAISS · Sentence Transformers · Transformers · PyTorch

### [Invoxi](https://invoxi.net)

An invoicing web application with an invoice builder and a Vercel deployment workflow. My work spans the application and its release readiness, including domain routing and dependency maintenance.

**Stack:** Next.js · React · TypeScript · Supabase · Vercel

### [Cyber LLM Vulnerability Pipeline](https://github.com/Abudirrr/cyber-llm-pipeline)

A Python pipeline for collecting and enriching vulnerability records from NVD, CISA KEV, Exploit-DB, and other security sources. Includes structured dataset outputs and scheduled GitHub Actions configuration.

### [Hire a Hero](https://github.com/Abudirrr/Superhero-Database)

A Django application with hero browsing, filters, category-based recommendations, user roles, hiring flows, cart models, and ratings.
